# DominionCard
 Dominion Card Generator
You can find the project at this link https://andrewcoder43.github.io/DominionCard/. 

**How it works**
Clicking on the Dominion Randomizer page will display ten random dominion cards that you can use to start your next dominion game.
Their is a Randomize cards button that will generate a list of ten cards at random that you can use for your dominion games.
The ability to filter by dominion set & card features is down below. The filters activate by clicking the empty check boxes to display a check mark.
