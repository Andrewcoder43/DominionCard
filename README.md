# DominionCard

Dominion Card Generator. This project helps you generate random sets of Dominion cards for your games.

You can find the project at this link: https://andrewcoder43.github.io/DominionCard/.

## How It Works

Clicking on the Dominion Randomizer page will display ten random dominion cards that you can use to start your next dominion game.
Their is a Randomize cards button that will generate a list of ten cards at random that you can use for your dominion games.
The ability to filter by dominion set & card features is down below. The filters activate by clicking the empty check boxes to display a check mark.

## Features

- Generates random sets of Dominion cards.
- Provides a user-friendly interface to display the cards.
- Allows filtering by Dominion set and card features.
- Includes a "Randomize Cards" button for generating new sets.
- Includes a page of recommended kingdoms.
- Includes a page of rules.

## Installation

1.  Clone the repository:

    ```bash
    git clone https://github.com/Andrewcoder43/DominionCard.git
    ```
2.  Navigate to the project directory:

    ```bash
    cd DominionCard
    ```
3.  Install the dependencies:

    ```bash
    npm install
    ```

## Usage

1.  Start the application:

    ```bash
    npm start
    ```

    This will start the development server and open the application in your default web browser.
2.  Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

    The page will reload if you make edits.
    You will also see any lint errors in the console.
3.  Click on the "Dominion Randomizer" link to generate a random set of Dominion cards.
4.  Use the filters to narrow down the card selection based on your preferences.
5.  Click the "Randomize Cards" button to generate a new set of random cards.
